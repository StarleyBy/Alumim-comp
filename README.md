# מערכת שיבוץ מחשבים וספרייה • בית הספר עלומים חולון (CompAlumim)

אפליקציית ווב מודרנית, מהירה ונגישה בעברית מלאה (`RTL`), **מותאמת במיוחד למסכי סמארטפונים** (Mobile-First Ultra-Compact) עבור אחראית המחשבים (טטיאנה) וצוות המורים בבית הספר **עלומים חולון**.

---

## 🌟 מאפיינים ועדכונים עיקריים

1. **מותאם ב-100% לסמארטפונים ללא גלילה מיותרת**:
   - כל הטבלה נכנסת במסך הנייד במבט אחד!
   - עמודות קבועות ל-6 ימי הלימוד (א׳ עד ו׳) ועמודת מספרי שיעורים קומפקטית.
   - **הוסרו שעות תחילת וסיום השיעור** – מוצג רק מספר השיעור (1 עד 8) לחיסכון מרבי במקום.

2. **כפתור מעבר מהיר בין כיתות/חללים (Segmented Control)**:
   - כפתור טאגל מהיר בראש העמוד למעבר נוח בלחיצה אחת:
     - 💻 **חדר מחשבים** (32 עמדות)
     - 📚 **ספרייה** (15 מחשבים ניידים)
   - כל חלל מוצג בנפרד במסך מלא ונקי.

3. **נעילת שיעור קבוע ללא שורה מבוזבזת**:
   - בשיעור קבוע מופיע **אייקון מנעול קטן (🔒) בפינת התא** בלבד, ללא בזבוז שורת טקסט בתא.
   - **הרשאות**: רק מנהלת המערכת (טטיאנה) יכולה לערוך או למחוק שיעור קבוע. משתמשים רגילים מקבלים הודעת נעילה.

4. **מצב בהיר ומצב כהה (Light & Dark Theme)**:
   - כפתור טאגל ייעודי בראש העמוד (🌙 / ☀️) למעבר בין מצב כהה מודרני למצב בהיר.
   - שמירה אוטומטית של העדפת המשתמש ב-`localStorage`.

5. **צבעי רקע אישיים**:
   - לכל מורה, כיתה ומקצוע מוגדר **צבע רקע אישי** משלו בתגית קומפקטית.
   - עריכת צבעים פשוטה דרך פאנל הניהול של טטיאנה.

6. **שמירה דינמית בין שבועות**:
   - השיבוצים השבועיים נשמרים ברצף בין השבועות עד לעריכת משתמש.

7. **זיהוי חגים ומועדים בישראל**:
   - חישוב אוטומטי מובנה של חגים יהודיים ולאומיים המוצגים באייקון עדין בכותרת היום (🎉/🕯️).

8. **כניסה סודית למצב מנהלת (טטיאנה)**:
   - הקשה רצופה **5 פעמים על סמל הלוגו (💻)** או לחיצה על `Alt + Shift + A`.
   - פתיחת פאנל עריכת מורים, כיתות, מקצועות, בחירת צבעים וסנכרון Google Sheets.

9. **סנכרון מלא ל-Google Sheets ו-Offline-First**:
   - עובד ישירות בדפדפן, ובחיבור ל-Google Apps Script מסנכרן בזמן אמת בין כל המכשירים.

---

## ☁️ חיבור Google Sheets (בקצרה)

1. צרו גיליון חדש ב-Google Sheets.
2. לחצו: **Extensions (הרחבות)** -> **Apps Script**.
3. הדביקו את הקוד מתוך [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
4. לחצו: **Deploy (פריסה)** -> **New deployment (פריסה חדשה)** -> **Web app (אפליקציית אינטרנט)**.
5. הגדירו: Execute as = "Me", Who has access = "Anyone".
6. העתיקו את כתובת ה-URL, היכנסו למצב מנהלת (5 לחיצות על הלוגו) -> הדביקו בלשונית Sheets ושמרו!
